# Contributing to Repo

We welcome your contribution for this repository.

We hope this repository to be organized.
Thus, please follow these contributing rules.

## Contribution Policy

Please read [Code of Conduct](./CODE_OF_CONDUCT.md) before you make your first contribution.

We require every contribution to close one or more issue(s) or discussion topic(s) at the time of Pull Request.

## How to Contribute

Please follow the following steps when you contribute to this repository.

### Step 1 Check or Publish Issue or Discussion Topic

Please check the Issues page before you start to modify this repository. Since you have to link your contribution to at least an issue or discussion topic, please check out the discussion topics and issues carefully.

When you cannot find any open issues or any discussion topics to link your modification, please make a new issue or discussion topic to notify other contributors of your contribution plan.

### Step 2 Fork This Repository

Please fork this repository's `main` branch to avoid the concurrencies.

### Step 3 Make Your Modification Branch

In the forked repository, please make a branch with name of the combination of one of the following prefix and your contribution name.

#### Branch Prefixes

The prefix names depend on your contribution types.

| Contribution Summary  |   Prefix   |
|:----------------------|:----------:|
| Bugfix                | `bugfix/`  |
| Addition of a Feature | `feature/` |
| Mixed Contribution    | `mixed/`   |

### Step 4 Make Your Modification

Please make your modifications on the forked repository's branch you created in the previous step.

Please leave comments occationally on the linked discussion topics and issues. Please do not close them before you make a Pull Request.

### Step 5 Test Your Repository

Using the workflows, please test your forked repository on your computer and on GitHub.

Please return to the previous step until all tests pass on both your computer and on GitHub.

### Step 6 Make a Pull Request.

Please make a Pull Request using the template.

Please fill every section of the Pull Request Template.
